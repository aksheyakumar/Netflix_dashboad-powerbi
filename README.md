# Netflix_dashboad-powerbi

**1. Netflix Dashboard : Netflix Insights Dashboard**
  This is an interactive dashboard where we show different types of charts from these charts we can see what type of content is popular or most watched around the world.

**2. Description :**
   The Netflix Analytics dashboard is a visually engaging and analytically designed power bi dashboard where we found out that approximately 70% of the content on Netflix consists of Movies, while only 30% are TV Shows. This indicates a strong preference for movies, likely because TV shows require a longer time commitment across multiple seasons, whereas movies are easier to watch in one sitting. There has been a significant surge in content volume after 2020 compared to previous years. This highlights Netflix's rapidly growing popularity worldwide and shows how new creators are increasingly leveraging the platform to share their stories.

**3.Tech-Stack :**
The dashboard was built using the following technologies:
 * 📊   **Power Bi Desktop :** The main data visualization platform for dashboard creation.
 * ⚡   **Power Query :** here we clean and transform the data using power query.
 * 📂   **File Format :** '.pbix' for dashboard and '.png' for dashboard preview

 **4.Data Source:**
   **Source :** www.kaggle.com(Netflix Dataset)
